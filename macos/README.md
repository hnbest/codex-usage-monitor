# Codex Usage Monitor macOS 版

macOS 13 或以上版本可使用这个独立的 Swift 工程。菜单栏、详情、总览和设置使用 SwiftUI，置顶浮窗使用 AppKit。

## 在 Mac 上运行

1. 在 Mac 上用 Xcode 打开 `CodexUsageMonitor.xcodeproj`，选择 `CodexUsageMonitor` 和 `My Mac`，按 `⌘R`。
2. 点击菜单栏图标打开详情，或从「更多操作」显示置顶浮窗。
3. 程序读取 `CODEX_HOME/auth.json`，默认路径是 `~/.codex/auth.json`。如果通过 Finder 启动，应用使用系统传入的环境，终端配置文件中定义的变量可能不可见。
4. 如果当前登录只保存在系统钥匙串，可以从设置中「添加独立账号」。应用用独立的 `CODEX_HOME` 启动终端登录，完成后保存为账号快照。登录期间请保持监控程序运行，以便自动接收结果。需要切换 CLI 时，请先确认 CLI 使用文件凭证。

## 生成安装包

在安装了 Xcode 的 Mac 上，从仓库根目录执行：

```bash
bash macos/build-dmg.sh
```

脚本生成 Apple 芯片和 Intel 通用的 `.dmg`，并把 SHA-256 校验文件写到 `macos/dist/`。双击 DMG 后，将应用拖到「应用程序」。脚本使用临时签名。通过网络下载的安装包可能需要在 macOS「系统设置 → 隐私与安全性」里选择「仍要打开」。正式对外分发可使用 Developer ID 签名并公证。

## 与 C# 版功能对应

- 双环额度、重置倒计时和液位、订阅起止时间、重置卡数量、明细和临近到期提示。
- 菜单栏同时显示两项额度，支持单账号详情和多账号总览。菜单栏数字提供 Windows 任务栏小窗对应的常驻入口。
- 全账号定时刷新、手动刷新、低额度系统通知，以及检测 CLI 凭证更新后自动刷新。
- 当前账号归档、独立登录、失效账号重新登录、备注和移除快照。切为 CLI 前先归档当前登录，再原子替换凭证，可手动确认重启 Codex 桌面端。
- 设置浮窗透明度、三档界面字号、采集间隔、菜单栏额度和登录时启动。浮窗位置自动保存，设置页显示版本号。

账号快照使用与 C# 版相同的 `auth.json` 和 `meta.json` 文件结构，保存在 `~/Library/Application Support/CodexUsageMonitor/accounts/`。这些文件含登录凭证，请保留在本机。检查新工程时，优先确认菜单栏刷新，再使用两个测试账号验证隔离登录、切换、续期和桌面端重启。
